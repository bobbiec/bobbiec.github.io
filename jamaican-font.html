This text box contains ordinary text that you can select, copy, and search. The colors and shapes are built directly into the font!

The Connected Variant joins letters together, using contextual font features to match background colors between letters and connecting certain glyphs.

A project by Bobbie Chen, based on the Jamaican alphabet by u/VelvetOnion.
